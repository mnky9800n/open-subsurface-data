The license covers the index: the selection, the descriptions, the checksums, the header summaries, the grid
fits, the well-to-volume ties and the outcome columns. It does not cover the data the index points to. Each
source keeps its own terms, listed in `sources.csv`:

- USGS NAMSS: public domain.
- SARIG: CC BY 4.0; keep the disclaimer file that ships in each zip.
- BOEM Data Center and File Request System: public information that "may be distributed or copied"; credit BOEM.
- NETL EDX: "No License Restrictions" or Open Data Commons Attribution, per data set.
- LDEO LogDB: CC0 for the IODP files; no license stated for the Gas Hydrate JIP and DSDP files.

The well tables are derived from BOEM public data. The seismic header tables are derived from NAMSS and SARIG
files. Nothing in this folder comes from Diskos or any other members-only repository.
